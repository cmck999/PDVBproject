PDVoice Buddy

One icon, one flag, one button. Click the icon and the flag appears in the corner already listening. There is no main window, no dashboard, and nothing to set up before it works.

Turning the mic on

Click the PDVoice Buddy icon below — the browser will ask once for microphone access. If nothing happens, the preview frame is blocking it: open this page in its own browser tab and click the icon again. If you already said no, the flag shows Microphone blocked and its button turns into Allow; if the browser has stopped asking, click the padlock in the address bar, set Microphone to Allow, and reload.

A native build never asks twice — the shell app holds the permission for good, so the patient sees no prompt at all.
