01  /  The thing that changes everything
A fixed dB target cannot work on a phone.

Keeping the phone in reach helps, but it does not fix this. Arm's length to the far side of a place setting is still a 6 dB swing. And the bigger problem is the room itself: a restaurant runs 30 dB louder than her kitchen, so one fixed number cannot serve both.

So the phone version measures something else: how far the voice rises above the room. That number stays honest whether the phone is near or far, and it happens to be the thing that actually matters — being audible isn't about decibels, it's about beating the noise you're competing with. Drag the sliders and watch the fixed target fail.

03  /  Getting it on screen without a ritual
The best version needs no launching at all.

Three real routes onto a locked screen, and they are not equally good. The one you probably have not heard of is the strongest: Android's screensaver fires automatically when a phone is docked and charging — which is exactly how we already want it sitting at the table.

Best — start here
Android 4.2+
Screensaver on a charging stand

Register the ring as a DreamService — Android's screensaver. It takes over the whole screen automatically whenever the phone is docked or charging, and exits the moment she touches it.

Set it once in Settings, and from then on the interaction is: put the phone on its stand. That's it. No unlocking, no icon, nothing to remember — and it solves the battery problem at the same time, because it only runs while plugged in.

Full screen · full framerate · no permission · works on every Android
Build alongside
Android 8.1+
Show-when-locked screen

One line — setShowWhenLocked(true) — lets the ring appear over the lock screen without unlocking. It's the same mechanism alarm clocks and incoming calls use, so it is rock solid on every phone.

The catch is that something has to launch it. A tap on the icon works; an NFC sticker under a coaster works better.

A lock screen widget

This is what you were picturing, and it does now exist — Google brought lock screen widgets back for tablets in 2024 and for phones at the end of 2025.

But widgets draw through a slow cross-process mechanism built for weather and calendars, not for something that has to keep pace with speech. A smooth glowing ring is not achievable. Support also varies by manufacturer, so a Samsung may not have it at all.

Walking and driving are the cases that genuinely cannot be solved with a screen — the first because nothing is in view, the second because nothing moving should be. Both are why the phone's own vibration is worth building before any watch. A pocket muffles the microphone badly in absolute terms, but it muffles her voice and the room by roughly the same amount, so the above-the-room measurement partly survives where a fixed dB target would be hopeless. Imperfect, and it needs testing rather than trusting. But it means a free buzz in the pocket may cover the walking case without buying anything.

Cheap trick

An NFC sticker costs about a pound. Stick one under a coaster or her table mat, program it to open the app, and setting the phone down on that spot is the launch. It turns the one remaining requirement — remembering to start it — into a physical habit with no screen involved. Works today, no code needed.

04  /  The engine, split out
One file with no Android in it.

You asked for an app now that could become a library later. That happens by keeping the measurement in pure Kotlin that imports nothing from Android — it takes numbers in and gives a verdict out. The app feeds it the microphone; a library, a watch, or someone else's app feeds it something else.

It's the same maths already running in the Python app, so behaviour stays consistent across everything you build. Roughly 120 lines.

class VoiceCue(
    val marginDb: Float = 12f,   // how far above the room
    val holdMs: Long = 700,      // ride through word gaps
) {
    private var floor = 40f      // slow room-noise estimate
    private var lastAbove = 0L

    /** One frame of mono PCM. Returns the cue state. */
    fun push(samples: FloatArray, now: Long): State {
        val db = 20f * log10(rms(samples).coerceAtLeast(1e-7f))

        // The room floor tracks slowly; speech never drags it up.
        floor = if (db < floor) lerp(floor, db, 0.05f)
                else lerp(floor, db, 0.0008f)

        val above = db - floor
        if (above >= marginDb) lastAbove = now

        return State(
            lit      = now - lastAbove < holdMs,
            aboveDb  = above,
            level    = (above / (marginDb + 8f)).coerceIn(0f, 1f),
            isSpeech = above > 6f,
        )
    }

    data class State(
        val lit: Boolean,      // drives the ring
        val aboveDb: Float,    // dB over the room
        val level: Float,      // 0..1, for glow and thickness
        val isSpeech: Boolean, // counts toward the daily %
    )
}
No imports, no context, no permissions. Testable on a laptop with no phone attached — which is how you'd know it works before trusting it.
